## About

This repository contains the source code for **Clarenze Kenshien A. Alao's personal portfolio**, available at **[kenshien.is-a.dev](https://kenshien.is-a.dev/)**.

The portfolio presents my work as a web developer, including the websites, web applications, and software projects I have built. It provides an overview of my technical skills, development experience, and approach to building modern, performant, and user-focused applications.

## Features

- **Featured Projects** — Showcase of selected web applications and software projects with descriptions, technologies, and relevant links.
- **Technical Skills** — Overview of the programming languages, frameworks, libraries, and development tools I work with.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Modern UI** — Clean, accessible interfaces with smooth interactions and attention to usability.
- **Dark Mode** — Support for light and dark themes.
- **Performance-Focused** — Built with modern rendering, caching, and optimization practices.
- **Accessible Interface** — Designed with semantic HTML and accessibility considerations.

### Development Practices

- Type-safe application development with TypeScript on the frontend and Java on the backend
- Runtime schema validation with Zod for forms and API payloads, paired with Bean Validation group interfaces (`OnCreate` / `OnUpdate`) on the backend
- Server-side data prefetching with React Query dehydration and `HydrationBoundary` to minimize client-side request waterfalls
- Stale-while-revalidate caching strategy with configurable stale times, garbage collection tuning, and force-cache fallback on network failure
- Optimistic UI updates on mutations with automatic rollback via `cancelQueries`, snapshot restoration, and `onSettled` cache invalidation
- Incremental Static Regeneration (ISR) with time-based revalidation for optimal performance and content freshness
- React Compiler enabled for automatic memoization and render optimization without manual `useMemo` / `useCallback`
- Centralized Axios interceptor with silent JWT token refresh, automatic request retry on 401/403, and session expiry handling
- Secure JWT-based authentication using HTTP-only, Secure, SameSite, and Partitioned cookie attributes with access and refresh token rotation
- Tiered token-bucket rate limiting with Bucket4j and Caffeine, using per-endpoint categories for authentication, contact forms, and public reads
- Trusted proxy IP resolution using Cloudflare `CF-Connecting-IP` with secure origin configuration
- Centralized global exception handling with `@RestControllerAdvice` for consistent API error responses, including structured duplicate-key conflict parsing
- Request timeout enforcement with `AbortSignal.timeout` for resilient upstream calls
- SEO optimization with dynamic sitemap generation, programmatic robots.txt, JSON-LD structured data, and Open Graph metadata
- Component-driven architecture with domain-specific custom hooks for data fetching, authentication, and state management
- Layered backend architecture with dedicated service, repository, and controller layers
- Graceful degradation with `Promise.allSettled` for resilient parallel data fetching
- Responsive and accessible UI development using semantic HTML and ARIA considerations

## Purpose

This project serves as my professional portfolio and a central place to present my work in web and software development.

It demonstrates my ability to design and develop modern web applications across the frontend and backend, with an emphasis on **performance, maintainability, scalability, accessibility, and user experience**.

The portfolio is also intended to provide recruiters, developers, and potential collaborators with an overview of my technical capabilities and projects.

## Development

The portfolio is built using the **Next.js App Router** and follows a component-based architecture with TypeScript.

The project focuses on maintaining a clean and maintainable codebase while taking advantage of modern web development practices such as responsive design, type safety, API integration, client-side caching, and performance optimization.
